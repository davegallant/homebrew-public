# homebrew-public

This is a public homebrew tap containing formulae and casks.

To install a formula:

```sh
brew install davegallant/public/<Formula>
```

For example: `brew install davegallant/public/rfd`

To install a cask:

```sh
brew install --cask davegallant/public/<Cask>
```

For example: `brew install --cask davegallant/public/vpngate-mac`
